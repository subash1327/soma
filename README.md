# Soma — Personal Portfolio

Vite + vanilla HTML/CSS/JS, hosted on Firebase Hosting.

## Develop
    npm install
    npm run dev

## Deploy
    npm install -g firebase-tools
    firebase login
    # set your project id in .firebaserc (replace YOUR-FIREBASE-PROJECT-ID)
    npm run build
    firebase deploy
